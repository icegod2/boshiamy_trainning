# 無蝦米開機複習訓練程式

每次登入桌面時自動跳出的無蝦米打字複習視窗。從你自訂的練習清單抽題，
用系統的無蝦米輸入法打出正確的字才能離開；累計答錯 5 次也可放棄離開。

## 使用方式

1. 編輯 `words.txt`，把常打錯的字加進去（格式：`字 編碼`，編碼選填）。
2. 手動測試：`python3 trainer.py`
3. 安裝開機自動啟動：`./install.sh`
4. 移除：`./install.sh --uninstall`

## 規則

- 每次抽 3 題（`config.json` 的 `questions_per_session` 可調）。
- 用無蝦米打出顯示的字，按 Enter 送出。
- 同一字答錯 3 次後顯示無蝦米編碼提示（`hint_after_failures`）。
- 一輪結束後，答錯過的字會再測一輪，直到某一輪完全沒錯才能離開。
- 累計答錯 5 次（`max_failures`）會出現「放棄離開」按鈕。
- 在那之前視窗無法關閉，貼上（Ctrl+V 等）也被擋住。

## 加強複習機制

答題紀錄存在 `stats.json`（自動產生，不用手動編輯）。
抽題時錯誤率高、久沒練的字權重較高，所以常錯的字會更常出現。

## 檔案

| 檔案 | 說明 |
|---|---|
| `trainer.py` | 主程式（tkinter GUI） |
| `words.txt` | 練習清單（手動維護） |
| `config.json` | 題數、失敗上限等設定 |
| `stats.json` | 答題紀錄（自動產生） |
| `install.sh` | 安裝/移除開機自動啟動 |
